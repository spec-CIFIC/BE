# 🐬 CIFIC — specIFIC

> 인강·교재로 배운 내용을, 내 약점만 골라 AI가 무한히 문제로 뽑아주고,
> 오답노트까지 자동으로 만들어주는 복습·연습 파트너.
>
> 첫 타깃 시험: **CPA(공인회계사)**

---

## 우리가 푸는 문제

자격시험 수험생이 실제로 겪는 세 가지 고통:

| 고통 | 현실 |
|---|---|
| **막막함** | 어디가 약한지 스스로 알기 어렵고, 정보는 커뮤니티에 흩어져 있다 |
| **오답노트 수작업** | 거의 모든 수험생이 손으로 오답노트를 만든다 |
| **약점 반복량 부족** | 기출은 유한하고, 좋은 문제는 강사에게 큰돈을 내야 한다 |

기존 인강·교재는 "가르치기"는 잘합니다. 하지만 **개인의 약점을 진단하고 그 지점만 무한 반복시키는 기능**은 비어 있습니다. **그 빈자리가 CIFIC의 자리입니다.**

---

## 솔루션

CIFIC은 인강·교재의 **대체재가 아니라 보완재**입니다.

> "이걸로 공부해라"가 아니라, "네가 약한 부분만 여기서 무한 반복해라."

**CIFIC이 하는 일 세 가지:**

1. **약점 진단** — 내 풀이 기록을 분석해 어떤 개념이 약한지 짚어준다
2. **맞춤 문제 무한 생성** — 그 약점만 겨냥한 문제를 AI가 계속 만들어준다
3. **자동 오답노트** — 틀리면 왜 틀렸는지 분석해 오답노트를 자동으로 쌓아준다

---

## 왜 CPA·회계부터인가

취향이 아니라 **기술적으로 성립하기 때문**입니다.

회계·세무의 계산 문제(감가상각·원가계산·세액계산)는 답이 딱 떨어집니다. 즉, AI가 문제를 제대로 만들었는지 **코드로 채점**할 수 있습니다.

> 💡 **핵심 통찰: 생성은 못 믿어도, 검증(채점)은 믿을 수 있다.**
> 이것이 CIFIC이 정확도를 자신하는 근거입니다.

---

## 신뢰를 어떻게 보장하나

AI가 만든 문제를 그대로 내보내지 않습니다. 모든 문제는 **5개의 관문**을 통과합니다.

| 단계 | 검증 내용 |
|---|---|
| 1. 구조 검증 | 선지 개수, 정답 존재, 해설 누락 등 형식 |
| 2. 계산 검증 **(핵심)** | 풀이 코드를 실행해 주장한 정답과 대조 |
| 3. 교차 검증 | 정답을 숨기고 다른 AI가 풀게 해 답 일치 여부 확인 |
| 4. 근거 대조 | 해설이 실제 조문·기준과 맞는지 (개정 세법 오류 방지) |
| 5. 기출 유사도 | 기출과 너무 비슷하면 폐기 (저작권 보호) |

## 로드맵

| 버전 | 목표 |
|---|---|
| **v0** | 생성 → 코드 실행 → 대조 루프 데모 |
| **v1** | 실제로 풀 수 있는 형태 |
| **v2** | 자동 승인율 % 측정 가능 |
| **v3** | 플라이휠 가동, 소규모 베타 |
| 이후 | CPA 전과목 → 세무사 → 관세사 확장 |
